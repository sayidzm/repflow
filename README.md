# RepFlow

Offline-first workout tracking app for Android and iOS, built with React Native, Expo, TypeScript, Expo Router, and Expo SQLite.

## Commands

```sh
pnpm start
pnpm android
pnpm ios
pnpm typecheck
pnpm lint
pnpm test
```

Product and engineering context lives in `prd.md`, `project_goals.md`, and `memory-bank/`. `referances_design/` is a read-only design source and is not runtime code.
